# Howitzer Duel

Two players, one screen. Set elevation and charge, then fire.

**[Play Howitzer Duel](https://dustinrjo.github.io/howitzer-duel/)**

The game is a single static file, [`index.html`](index.html).

## Controls

- ↑ ↓ Elevation ±1°
- ← → Charge ±1
- Shift Fine steps of 0.1
- Space Fire
- R New match
- M Sound on or off
